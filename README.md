# react-native-smooth-clip-view

Layout-free animated rounded clipping for React Native Fabric

## Installation


```sh
npm install react-native-smooth-clip-view
```


## Usage


```js
import { SmoothClipViewView } from "react-native-smooth-clip-view";

// ...

<SmoothClipViewView color="tomato" />
```
